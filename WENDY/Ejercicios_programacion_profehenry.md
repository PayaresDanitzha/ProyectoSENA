## Ejercicio hecho en javascript 

function main() {
  let k = " 20 ";
  console.log("MI EDAD ES " + k + "AÑOS");
}

main();

En java "Let" se puede remplazar por "Const"
En resumen, En este ejercicio se declara una variable de tipo String que contiene la edad "20". Luego, mediante System.out.println() y el operador +, se concatena la variable con otros textos para mostrar en pantalla el mensaje "MI EDAD ES 20 AÑOS".
