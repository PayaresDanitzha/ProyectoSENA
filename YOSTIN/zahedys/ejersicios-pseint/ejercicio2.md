
# Algoritmo para saber si una persona es mayor o menor de edad

## Descripción

Este algoritmo solicita al usuario que ingrese su edad y luego verifica si es mayor o menor de edad. Para esto se utiliza una condición `Si`.

## Código en PSeInt

```pseint
Algoritmo sin_titulo

    Definir edad Como Entero

    Escribir "Digite su edad"
    Leer edad

    Si edad >= 18 Entonces
        Escribir "Es mayor de edad"
    Sino
        Escribir "Es menor de edad"
    FinSi

FinAlgoritmo
```

## Funcionamiento

Primero, el programa solicita al usuario que digite su edad. Después, mediante la condición `Si`, comprueba si la edad es mayor o igual a 18.

* Si la edad es **18 o más**, muestra: **"Es mayor de edad"**.
* Si la edad es **menor de 18**, muestra: **"Es menor de edad"**.
